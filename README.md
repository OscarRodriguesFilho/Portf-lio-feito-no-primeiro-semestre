# Portfólio — Oscar Rodrigues

Página estática (HTML + CSS + um punhado de JS, sem framework) com o catálogo
das aplicações que estão no ar, os repositórios públicos, trajetória, entidades
e contato.

- `index.html` — conteúdo e o filtro do catálogo
- `style.css` — paleta e layout
- `img/apps/` — capturas de tela das aplicações

Publicado via GitHub Pages:
https://oscarrodriguesfilho.github.io/Portf-lio-feito-no-primeiro-semestre/
